# Segnetics Pixel Studio

[English](README.md) | **Русский**

Открытый инженерный инструментарий, оптимизатор памяти и интерактивный цифровой двойник для программируемых логических контроллеров **Segnetics Pixel** (серии 12xx и 25xx на базе микроконтроллера ATmega2560).

Решает проблему переполнения памяти контроллера в SMLogix (ошибка *«Ошибка загрузки строковых констант. Недостаточно памяти для проекта»*) и позволяет разрабатывать, компилировать и тестировать логику FBD без физического контроллера на стенде.

---

## Основные возможности

### 1. Аудит и оптимизация памяти проектов SMLogix (`audit`, `optimize`)
* **Аппаратный аудит:** структурный разбор бинарных файлов проектов `.psl` и бэкапов `.bk1`, сопоставление с физическими лимитами ATmega2560 (256 КБ Flash, 32 КБ SRAM, 4 КБ EEPROM).
* **Сжатие и очистка от балласта:** автоматическое обнаружение и обрезка сотен дублирующихся анимационных раскадровок SMArt до системных пиктограмм. Проект сжимается в 2.5–3 раза без потери структуры экранов и меню.
* **Экспорт ресурсов (`export-smart`, `export-logic`):** извлечение встроенной базы данных SQLite3 (`translation`, `language`, `composite`), таблицы экранов и схемы блоков в формат JSON.

### 2. Декларативный FBD DSL и среда исполнения (`src/core/`)
* **Разработка алгоритмов на чистом Python:** создание функциональных схем через декларативный API вместо ручной расстановки блоков мышью на холсте SMLogix.
* **Библиотека блоков (20+ типов):**
  * Логика: `AND`, `OR`, `NOT`, `XOR`;
  * Арифметика: `ADD`, `SUB`, `MUL`, `DIV` (с аппаратной защитой от деления на ноль);
  * Компараторы: `CMP`, `EQ`, `NE`, `GT`, `GE`, `LT`, `LE`;
  * Таймеры и счетчики: `TON`, `TOF`, `TP`, `CTU`, `CTD`;
  * Триггеры и память: `RS` (с приоритетом сброса), `SR` (с приоритетом установки);
  * Мультиплексирование: `MUX`, `SEL`, ограничитель `LIMIT`.
* **Потактовый топологический рантайм (`fbd_runtime.py`):** детерминированное вычисление связей за один такт с учетом одноцикловых импульсов и триггерных ячеек.

### 3. Интерактивный цифровой двойник и веб-эмулятор (`src/pixel_studio/`)
* **Заводской корпус Pixel 2514:** фотореалистичная лицевая панель, ЖК-матрица STN с отрисовкой меню SMArt, тактильные кнопки (ESC, Right, Up, Down, OK) и светодиодные индикаторы реле и аварии.
* **Интерактивный тайм-скруббер (Time-Travel Scrubber):** ползунок истории позволяет отмотать время назад и покадрово увидеть, как вели себя сигналы, реле и экран контроллера на любом этапе работы.
* **Живые сигналы FBD (F9 Debug):** динамическая таблица значений на входах и выходах каждого функционального блока в реальном времени.
* **Форсирование входов (IO Force):** ручное переключение дискретных входов `DI 0..5` и аналоговых датчиков `AI 0..2` через ползунки.
* **Ускорение времени (Time Warp):** переключение скорости эмуляции: 1x (реальное время), 10x, 60x (1с = 1м), 600x, 3600x (1с = 1ч) и мгновенная пауза.
* **Полный заводской сброс:** кнопка сброса с модальным окном подтверждения (требует ввода слова `сброс` или `reset`).
* **Встроенный Modbus TCP Slave:** сервер на порту `15502` (Unit ID: 1) с автоподбором резервного порта при занятости. Позволяет подключать внешние SCADA-системы, Home Assistant или Node-RED.
* **Готовые проекты:** Насосная станция с ротацией насосов, Приточная вентиляция AHU с ПИД-регулированием и Двухконтурный термостат.

## Быстрый старт

### Требования
* Операционная система: Windows, Linux или macOS;
* Python 3.8 или новее.

### Запуск через пакетный файл (Windows)
Дважды кликните по файлу:
```cmd
run_pixel_studio.bat
```
В открывшемся интерактивном меню выберите нужное действие:
* `[1]` Запуск веб-эмулятора Pixel Studio (Web: 18088, Modbus: 15502)
* `[2]` Аудит памяти проекта .psl
* `[3]` Оптимизация и сжатие проекта .psl
* `[4]` Запуск полного набора автоматических тестов
* `[5]` Инструкция по заливке в реальный ПЛК через RS-485

### Запуск через командную строку (CLI)

```bash
# 1. Запустить веб-студию и Modbus TCP сервер
python -m src.pixel_studio.cli simulate --port 18088 --modbus-port 15502

# 2. Проверить проект на переполнение памяти ATmega2560
python -m src.pixel_studio.cli audit путь/к/проекту.psl

# 3. Очистить проект от тяжелых анимаций
python -m src.pixel_studio.cli optimize исходный.psl чистый.psl --max-png 15

# 4. Экспортировать граф FBD в JSON
python -m src.pixel_studio.cli export-logic проект.psl --out logic.json

# 5. Извлечь базу данных и экраны SMArt
python -m src.pixel_studio.cli export-smart проект.psl --out-dir extracted_smart
```

## Заливка в физический контроллер по RS-485

1. Подключите преобразователь USB-RS485 (например, BOLID USB-RS485, Segnetics или ОВЕН) к клеммам RS-485 контроллера Pixel:
   * Клемма A (RS-485+) адаптера $\to$ клемма `+` на корпусе Pixel;
   * Клемма B (RS-485-) адаптера $\to$ клемма `-` на корпусе Pixel;
   * Экран кабеля $\to$ клемма GND.
2. Оптимизируйте проект утилитой `optimize`:
   ```bash
   python -m src.pixel_studio.cli optimize project.psl project_clean.psl
   ```
3. Откройте `project_clean.psl` в заводской среде **SMLogix**.
4. Нажмите `Ctrl+F7` («Записать проект»). Загрузка пройдет быстро и без ошибок нехватки памяти.
